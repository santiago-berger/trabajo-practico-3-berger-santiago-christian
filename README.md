# Trabajo Práctico III - Los Simpson

**Materia:** Taller de Lenguaje de Programación I
**Año:** 2026
**Alumno:** Berger Santiago Christian

## Descripción

Aplicación web que consume la API pública de The Simpsons API para mostrar
los personajes de la serie, buscar por nombre y ver el detalle de cada uno
en un modal.

## Tecnologías

- HTML5
- CSS3
- JavaScript (async/await, manipulación del DOM)
- Bootstrap
